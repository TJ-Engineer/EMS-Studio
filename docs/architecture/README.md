# Architecture documentation

Stable system descriptions belong here. Material decisions that constrain implementation belong in `decisions/` as numbered architecture decision records.

Product-level dependency, packaging, and platform policies live in [product policy](../product/README.md).

The [Software Design Descriptions](sdd/README.md) document the current system, platform, CAD, EM, desktop interfaces, and verification/support contracts. Update the affected SDD alongside implementation changes; use ADRs for material decisions.
