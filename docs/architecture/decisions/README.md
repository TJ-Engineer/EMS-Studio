# Architecture decision records

Use a four-digit sequence followed by a short name, for example `0001-document-revision-state.md`. Each record should contain the context, decision, alternatives, consequences, status, and date.

- [0001: Explicit CAD evaluator hydration before document restore](0001-explicit-cad-evaluator-hydration.md)
- [0002: Validated ASIR boundary for electromagnetic execution](0002-validated-asir-boundary.md)
